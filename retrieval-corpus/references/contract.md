# Retrieval contract — types

Open this when writing the stub, the contract tests or a client. The rules
are in [../SKILL.md](../SKILL.md). Language codes are BCP 47 tags; the
binding lists the corpus's languages and its tag vocabulary.

## Data model

```ts
type SourceId = string;
type FragmentId = string;          // "<source_id>@<version>:<start>-<end>"
type Lang = string;                // BCP 47, e.g. "en", "he", "ru"
type CorpusVersion = string;       // hash of all source versions + normalizer version

interface Source {
  source_id: SourceId;
  version: string;                 // first 8+ hex chars of SHA-256 of normalized text
  title: string;
  authors: string[];
  year: number | null;
  language: Lang;
  access: "open_access" | "paid" | "library" | "permission";
  verification: "V" | "C" | "K";
  url: string | null;
  tags: string[];                  // from the source registry, never generated by a model
  ingested_at: string;             // ISO-8601
}

interface Fragment {
  fragment_id: FragmentId;
  source_id: SourceId;
  source_version: string;
  span: { start: number; end: number };   // half-open, in normalized text
  text: string;
  page_start: number | null;
  page_end: number | null;
  section_path: string[];
  language: Lang;
}
```

## Operations

```ts
interface SearchRequest {
  query: string;
  k?: number;                      // default 8, max 50
  filters?: {
    languages?: Lang[];            // language of the source, not of the query
    source_ids?: SourceId[];
    tags?: string[];
    access?: Source["access"][];
    min_verification?: "V" | "C" | "K";
  };
  corpus_version?: CorpusVersion;  // if set and different: corpus_version_mismatch
}

interface SearchHit {
  fragment: Fragment;
  rank: number;                    // 1..k
  score: number;                   // debugging only; not comparable across requests
  matched_by: ("lexical" | "semantic")[];
}

interface SearchResponse { corpus_version: CorpusVersion; hits: SearchHit[]; }

interface GetRequest { fragment_id: FragmentId; context_chars?: number; }
// -> { corpus_version, fragment }; text may include context, span stays the original

interface VerifyRequest { fragment_id: FragmentId; quote: string; }
interface VerifyResponse {
  corpus_version: CorpusVersion;
  ok: boolean;
  matched_span?: { start: number; end: number };
  reason?: "not_found" | "too_short" | "unknown_fragment"
         | "version_gone" | "ellipsis_not_allowed";
}

interface ListSourcesRequest { filters?: SearchRequest["filters"]; }
// -> { corpus_version, sources: Source[] }

type ErrorCode = "invalid_request" | "unknown_fragment" | "version_gone"
               | "corpus_version_mismatch" | "unavailable";
```

The minimum quote length is a binding value (a default of 20 characters may
be too strict for languages with short words).

## Normalization steps

1. Unicode NFC.
2. Remove soft hyphens; join a word hyphenated at a line end
   (`exhaus-\ntion` → `exhaustion`).
3. Any run of whitespace → one space.
4. Quotes `“ ” « » „ ״` → `"`; apostrophes `’ ‘ ׳` → `'`; dashes `– —` → `-`.
5. Hebrew: remove vowel points and cantillation; remove LRM, RLM and other
   direction marks.
6. Case is unchanged.

## Quality-set case

```yaml
- id: q-001
  query: "<question>"
  filters: { tags: [<tag>] }
  expected:
    - source_id: <registry id>
      quote: "<verbatim passage, at least the minimum length>"
  k: 8
- id: q-002
  query: "<question in another language>"
  expected:
    - source_id: <registry id>
      page: <page>
```

## Transport

A suggested transport is an MCP server exposing `search`, `get`,
`verify_quote` and `list_sources`, so agents and the coordinator call the
same tools. A library is equally valid; the choice is the owner's. The stub
can use plain full-text search (for example SQLite FTS5) over the same
normalized text, without a semantic part, and must pass the same contract
tests.
